# Path of the Midnight Sun 누락 문자열 전수 점검

## 확인된 원인

기존 추출기는 `params.message/text/title/label/description`의 `defaultText`만 수집했습니다. 게임은 이 밖에도 다음 위치에 실제 표시 문자열을 보관합니다.

- `gs.ChangeStringVariables.params.textValue.defaultText`
- 데이터 개체의 `name.defaultText`
- 일부 `gs.CallCommonEvent` 매개변수의 `defaultText`

따라서 일반 대사는 대부분 번역됐지만, 변수로 조립되는 선택지·기술 설명·튜토리얼·UI 문자열과 일부 데이터 이름이 누락됐습니다.

## 1차 전수 검사 결과

- 전체 `defaultText`: 21,752개
- 현재 한글 없이 영문이 남은 `defaultText`: 6,142개
- 이 가운데 `textValue` 영문: 3,811개
- `textValue`에서 사용자 표시 가능성이 높은 문자열: 3,453개
- 선택지 본문: 905개 / 고유 문장 786개
- 동적 기술명·기술 설명 후보: 532개
- 직접 확인된 튜토리얼 후보: 23개
- 동적 UI 문자열 후보: 1,124개
- 데이터 `name.defaultText`: 673개(아이템·기술·적·내부 개체명이 섞여 있어 분류 필요)
- 공통 이벤트 매개변수 문자열: 245개(지역명·획득 알림·내부 분기명이 섞여 있어 분류 필요)

`dummytext`, 내부 라벨, UID, 리소스 경로, 분기 태그 등은 번역하면 게임 동작이 깨질 수 있으므로 사용자 표시 문자열과 분리해야 합니다.

## 수정 방침

1. 모든 `defaultText` 위치를 수집하도록 추출기 확장
2. 표시 문자열과 내부 제어 문자열 분류
3. 선택지·인명·기술명·기술 설명·튜토리얼·UI를 우선 번역
4. 제어 코드와 분기 라벨 보존 검사
5. 현재 패치 상태를 별도 백업한 뒤 증분 패치
6. 실패 시 기존 한국어 패치 상태로 자동 복구

현재 설치된 패치는 일반 대사 번역은 유지되지만, 위 항목은 아직 보완되지 않은 상태입니다.
