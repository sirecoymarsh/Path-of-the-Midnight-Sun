# Path of the Midnight Sun 폰트 및 오류 검사 결과

> 추가 실기 점검에서 선택지·기술명·일부 튜토리얼의 별도 `textValue` 필드가 기존 번역 범위에서 누락된 것을 확인했습니다. 기존 16,508개 항목의 구조 검사는 통과했지만, 번역 범위 자체를 확장해 보완해야 합니다.

- 배치: 1,118개 레코드 / 16,508개 항목

- 원문·UID·제어 코드 보존: 통과
- 중복·누락·연속 배치 번호 검사: 통과
- defaultText 이외 구조 변경: 0개
- 용어집: 5,156회 검사 / 오류 0개

- 기술·테스트 문자열 15개는 별도 규칙으로 검사
- JavaScript 구문: 1,118개 스테이징 파일 모두 통과

## 폰트 검사

- 게임 내장 폰트(BelgranoMS, edoMS, Goodlight, SansitaMS, ThicketMS): 한글 글리프 없음
- Windows **맑은 고딕(Malgun Gothic)**: 한글 글리프 포함 확인
- 게임의 Chrome/Electron 계열 렌더러에서 내장 영문 폰트가 한글을 지원하지 않을 때 시스템 폰트로 대체 표시되는 것을 정적 테스트로 확인
- 시각 테스트 이미지: `path_midnight_sun_font_test.png`
